# Estudio Contable Scerbo

Sitio web profesional del **Estudio Contable Scerbo**, un estudio de contabilidad y consultoría empresarial con base en General Pirán y Mar del Plata, Buenos Aires.

## Acerca del proyecto

Desarrollado para la **Cra. Paula Scerbo**, este sitio presenta de forma clara y moderna los servicios contables que ofrece el estudio, que incluyen asesoramiento integral para monotributistas, responsables inscriptos, sociedades comerciales, cooperativas, importadores/exportadores, y más.

### Secciones principales

- **Inicio** — Hero con presentación del estudio, grilla de servicios, sección "Por qué elegirnos", responsabilidad social empresarial, y "Nos adaptamos a tus necesidades".
- **Servicios** — Listado completo de servicios contables con descripciones detalladas.
- **Otros servicios** — Servicios adicionales como liquidación de impuestos, constitución de sociedades, auditoría, planificación fiscal, etc.
- **Información** — Perfil profesional de la contadora (formación, especializaciones, matriculación).
- **Contacto** — Formulario de contacto para consultas.

## Stack tecnológico

- **Next.js 16** (App Router) — SSR, generación de rutas y metadatos dinámicos
- **React 19** — Componentes modernos con Server Components
- **TypeScript** — Tipado estricto
- **Tailwind CSS 4** — Estilos utilitarios con PostCSS
- **Lucide React** — Iconografía

## Desarrollo

```bash
npm install       # Instalar dependencias
npm run dev       # Servidor de desarrollo en localhost:3000
npm run build     # Build de producción
npm run start     # Servir build de producción
```

## Despliegue

El sitio está preparado para deploy en cualquier plataforma que soporte Next.js (Vercel recomendado).

Optimizado para SEO con Open Graph, sitemap y metadata completa en español.
